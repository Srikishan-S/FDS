SEEF — Self-Evolving Feature Engineering Framework

SEEF changes the feature representation when a stream changes. Its classifier weights stay fixed.

  1. Monitor: predict first, then measure performance after each label arrives.
  2. Detect: confirm a drift over two windows and create a fingerprint.
  3. Recall: find successful feature repairs from similar fingerprints.
  4. Evolve: generate and rank context-relevant transformations.
  5. Validate: test candidates on future samples and require repeated passes.
  6. Deploy: promote a passing feature, store the repair, and monitor for rollback.

This is a three-variable, binary synthetic research prototype with one replaceable feature slot. The browser computes its own results using detector approximations. The Python engine uses River and scikit-learn; outputs can differ between runtimes. Improvements and memory reuse are measured, never guaranteed.
